# VRWebView development diagnostics

Historical IME, GPU and Activity comparisons for maintainers. This package is a
local dependency of the repository's development project. It is not a dependency
of the public VRWebView package and is not needed by either consumer quick start.

Its Editor commands are under **VRWebView > Diagnostics**. The optional IME Probe
sample and the probe Android AAR live here. Runtime rendering and IME compatibility
binaries remain in the core package.

Keep the development package and core package from the same source revision.
