## Delivery

Primary: a Git UPM package at `Packages/com.t34400.vrwebview` in
`t-34400/SimpleUnity3DWebView`. Public installation reads this subdirectory's
package.json, not the development project's Packages/manifest.json.

Secondary: a deterministic `.tgz` generated by `Tools/build_upm.py`. It contains
exactly the consumer package. Do not distribute a project/source ZIP as the
runtime installation. The legacy unitypackage exporter remains a maintainer
utility; it is not the documented consumer installation path.

The package contains Runtime, setup/compatibility Editor code, English guides,
licenses and optional `Samples~/Browser`. It has no dependency on the browser
sample or on the diagnostics package. The browser remains an editable sample,
not a required runtime service.

Historical probes, probe Android AAR, IME sample and research notes are in
`Development~/com.t34400.vrwebview.diagnostics`. The repository's development
project opts in through a local file dependency. A Git-package consumer does not
install it. Existing MonoScript GUIDs are retained; XR adapter/feature assembly
identities remain stable for existing scenes/settings. The legacy VulkanProbe
assembly name now identifies only the shared XR adapter/compatibility features,
not the standalone GPU/IME probes.

## Build and inspect

```bash
python3 Tools/check_distribution.py
python3 Tools/build_upm.py --output /path/outside/project/VRWebView.tgz
```

On the maintainer's WSL machine, use `C:\Users\tmiyoshi\Downloads` through
`/mnt/c/Users/tmiyoshi/Downloads` for generated deliverables. The tool also writes
an inventory/SHA-256 manifest. The archive excludes Assets, ProjectSettings,
local caches and development diagnostics. Repeat builds must produce the same
archive bytes.

Before creating a release, install the Git package or tarball in a **new Unity
project** and check both paths independently:

1. Core only: no Browser sample or diagnostics installed; create the WebView
   scene, build an Android Player, navigate and enter page text.
2. Core plus Browser: import one sample copy, create the rich scene, build and
   check URL text input, links, menus, windows and persistence.

Cloud checks validate inventories, assembly references, GUIDs, licenses and
archive round trips. They do not substitute for fresh Unity type compilation or
Quest verification. Existing development-project success alone is not a clean
consumer installation test.

## License decision

Apache-2.0 is the project default from **0.1.0-preview.53**, following the
maintainer's decision. Root/core/development package LICENSE, NOTICE, metadata,
README and changelog are updated together. Retain the original copyright notice.
Previously published MIT versions keep their original grant.

Public source history was inspected: author names are t-34400, t34400 and
Takumi Miyoshi. This history check is not a claim that bundled upstream code is
owned by the project. Google GameActivity, the existing MIT compatibility helper
and patch tooling, Unity headers, LLVM runtime and external SDKs keep their own
licenses. The existing helper source retains its MIT SPDX notices and a separate
LICENSE; its tested prebuilt AAR is unchanged. See the core ThirdPartyNotices.md.
